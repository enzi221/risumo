identifier=poll
Use for a single-choice poll shared in the conversation. Write `content` on a single line as `question § label :: votes § label :: votes`. Use nonnegative integer vote counts and include at least two options. Apply the enclosing TOON string escaping to the complete payload.
Maintain the vote counts as the current totals for the poll. Include every established `poll-vote` message with the same question and a matching option. Count each voter at most once, using that voter's latest choice when the voter changes the vote. Never leave an established `poll-vote` unreflected in the matching poll. Allow partial participation and zero participation, including zero votes for every option.{{#when::lb-minitalk.speak::tis::0}} Leave the persona's vote uncast unless the user established the vote.{{/}}
