# CBS Guide

Use CBS in lorebooks, background embeddings, and regex replacement output to read state, transform text, and render conditional or repeated content.

## Syntax

- Write expressions as `{{name::argument::argument}}`. Arguments are text; omit quotation marks around ordinary strings.
- Nest expressions inside arguments, as in `{{trim::{{getvar::module_subject}}}}`.
- Open blocks with `#` and close them with `{{/}}`. An optional closing label identifies the opening block for readers; the parser does not require matching labels.
- Use `{{// comment}}` for CBS comments.

## Variables and names

- `{{char}}`, `{{user}}`: Character and user display names.
- `{{getvar::name}}`: Read a persistent chat variable, falling back to character and template defaults. An absent value returns the text `null`, not an empty string.
- `{{getglobalvar::toggle_module_option}}`: Read a module toggle named `module_option`. Prefix the toggle name with `toggle_`. Checkbox values are `0` or `1`; select values are option indices; text values are user input. An absent toggle returns the text `null`.

Use Lua for state changes in module interfaces.

## Conditions and comparisons

Read `references/001-cbs-cond.md` for `#when` operators, toggle checks, whitespace handling, and `:else`.

- `{{equal::A::B}}`, `{{notequal::A::B}}`: Case-sensitive string comparisons returning `1` or `0`.
- `{{greater::A::B}}`, `{{less::A::B}}`, `{{greaterequal::A::B}}`, `{{lessequal::A::B}}`: Numeric comparisons returning `1` or `0`.
- `{{and::A::B}}`, `{{or::A::B}}`, `{{not::A}}`: Boolean expressions. Only the exact text `1` counts as true, unlike `#when`, which also accepts `true`. `and` and `or` take two arguments.

Check both the missing-value sentinel and trimmed length for optional text:

```text
{{#when::keep::{{and::{{notequal::{{getglobalvar::toggle_module_subject}}::null}}::{{greater::{{length::{{trim::{{getglobalvar::toggle_module_subject}}}}}}::0}}}}}}
The subject: {{getglobalvar::toggle_module_subject}}
{{/when}}
```

## Strings

- `{{trim::text}}`: Remove leading and trailing whitespace.
- `{{length::text}}`: Count UTF-16 code units, not array elements or visible graphemes.
- `{{lower::text}}`, `{{upper::text}}`: Apply locale-aware case conversion.
- `{{contains::text::part}}`, `{{startswith::text::prefix}}`, `{{endswith::text::suffix}}`: Case-sensitive literal tests returning `1` or `0`.
- `{{replace::text::search::replacement}}`: Replace all literal, case-sensitive matches. The search argument is not a regular expression.
- `{{split::text::delimiter}}`: Split on a literal delimiter and return a JSON array of strings. Empty fields remain; splitting an empty string on a comma produces `[""]`, not `[]`.
- `{{join::array::separator}}`: Join array elements into text.

```text
{{split::red,green,blue::,}}
{{join::{{split::red,green,blue::,}}:: / }}
```

The results are `["red","green","blue"]` and `red / green / blue`.

## Arrays and objects

Supply JSON arrays to array expressions and `#each`.

- `{{arraylength::array}}`: Count elements. Use this instead of `length` for arrays.
- `{{arrayelement::array::index}}`: Read a zero-based index; negative indices count from the end. Out-of-range or JSON-null elements return the text `null`.
- `{{dictelement::object::key}}`: Read a JSON object's key. Missing or JSON-null values return the text `null`.
- Both element expressions serialize object or array results back to JSON, allowing nested access. Other results become text.
- `{{range::[end]}}`, `{{range::[start,end]}}`, `{{range::[start,end,step]}}`: Produce an ascending array of numeric strings, excluding `end`. Supply a positive step; zero or negative steps can prevent termination when `start < end`.

```text
{{dictelement::{{arrayelement::{{getvar::module_items}}::0}}::name}}
```

## Repeated rendering

Use `{{#each array as item}}...{{slot::item}}...{{/each}}` to repeat a body for each array element.

- Read the current element with the exact named slot `{{slot::item}}`, not `{{item}}` or `{{getvar::item}}`.
- String elements are inserted as text; other elements are JSON-serialized. Use `dictelement` on the slot to read object fields.
- The substituted body is parsed again, allowing nested expressions and conditions to consume the slot. Slot substitution is not HTML escaping or a literal-text boundary for untrusted content.
- Default `#each` trims the body and each line. Use `{{#each::keep array as item}}` to preserve whitespace. Iterations concatenate without an automatic separator.
- No index slot is supplied. Iterate over `range` and use `arrayelement` when an index is needed.

For a regex replacement whose `$1` capture contains comma-separated asset names:

```html
<div class="module-gallery">
{{#each {{split::$1::,}} as asset}}
<img alt="{{slot::asset}}" src="{{raw::{{trim::{{slot::asset}}}}}}">
{{/each}}
</div>
```

For a JSON array of objects in a chat variable:

```html
{{#each {{getvar::module_items}} as item}}
<span class="module-item">{{dictelement::{{slot::item}}::name}}</span>
{{/each}}
```

## Numbers

- `{{? expression}}`: Evaluate arithmetic and numeric comparisons. Supports `+`, `-`, `*`, `/`, `%`, `^`, `<`, `>`, `<=`, `>=`, `==`, `!=`, and parentheses. Nest variable reads inside the expression. Use `equal` or `notequal` for text comparisons.
- `{{round::number}}`, `{{floor::number}}`, `{{ceil::number}}`, `{{abs::number}}`: Round to the nearest integer, round down, round up, or take the absolute value.
- `{{tonumber::text}}`: Filter characters rather than parse a number. Keeps digits, decimal points, and whitespace; removes signs and other characters. `{{tonumber::-12i}}` returns `12`. Use only for extracting digits from controlled labels, not for signed-number conversion or validation.

## Assets and interaction

- `{{image::assetName}}`: Render an image asset as an `<img>` element.
- `{{raw::assetName}}` (alias of `path`): Return an asset path for an existing element's `src` or a CSS URL. This is not a general-purpose escaping expression.
- `{{button::label::triggerName}}`: Generate a `<button>` with `risu-trigger`. Write the element directly when module-specific classes or styling are needed.
- `{{trigger_id}}`: Read the clicked element's `risu-id` in a manual trigger; returns `null` when no ID was provided.

Read `references/000-lua.md` for stateful button handlers.

## Time

- `{{date}}`: Current local date without zero-padding, such as `2026-9-8`.
- `{{date::YYYY-MM-DD}}`, `{{date::HH:mm:ss}}`: Current local date or time with an explicit format.
