# CBS Guide

CBS is Risuai's templating syntax. Expressions open with `{{` and close with `}}`.

"Blocks" open with `#` and a name, such as `{{#when}}` or `{{#escape}}`. Blocks close with `{{/}}`. The closing marker can have any string appended, such as `{{/}}`, `{{/when-image}}`, or `{{/3}}`, regardless of the opening type. Use the appended string to identify the corresponding opening marker.

"Expressions" have neither the `#` prefix nor a closing marker.

Example of checking whether `lb-hn.subject` toggle exists and is not empty:

```
{{#when::keep::{{and::{{? {{length::{{trim::{{getglobalvar::toggle_lb-hn.subject}}}}}} > 0}}::{{? {{getglobalvar::toggle_lb-hn.subject}} != null}}}}}}
The subject: {{getglobalvar::toggle_lb-hn.subject}}
{{/}}
```

The following sections describe common expressions.

## General

- `{{? {expression}}}`
  - Runs math operations on numbers. Supports +, -, \*, /, %, ^ (expo), % (modulo), <, >, <=, >=, ==, !=, and parenthesis grouping.
- `{{getglobalvar::{name}}}`
  - Gets the value of a global variable by name. Returns "null" if the variable does not exist. Use it primarily to retrieve toggle values by appending `toggle_` to the `name` argument, such as `{{getglobalvar::toggle_displayImage}}` when the toggle name is `displayImage`.
- `{{getvar::{name}}}`
  - Gets the value of a chat variable by name. Returns an empty string if the variable does not exist.

## Conditionals

- `#if`, `#if_pure`, `#when`. Read resource `001-cbs-cond.md` to learn more.

## Strings

- `{{trim::{string}}}`
  - Returns the trimmed string.
- `{{length::{string}}}`
  - Returns the length of the string.

## Objects

- `{{dictelement::{object}::{key}}}`
  - Returns the value associated with a key from a JSON object or object string. Returns "null" if the key does not exist. Usage: {{dictelement::{"name":"John"}::name}} → John
- `{{arrayelement::{array}::{index}}}`
  - Returns an element from a JSON array or array string.

## Time

- `{{date[::{format}[::{ts}]]}}`
  - Formats a date and time using a custom format string. No arguments return YYYY-M-D. The first argument is the format string, and the second argument is a Unix timestamp. Usage: `date::YYYY-MM-DD`, `date::HH:mm:ss::1640995200000`
