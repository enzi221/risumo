# Lua API

All Lua scripts are ephemeral. They reset after execution, and each script runs in a separate context.

## Basic callbacks

Risuai supports `onInput`, `onOutput`, `onStart`, and `onButtonClick` callbacks, along with listeners registered through `listenEdit()`.

Define an `on...` callback by assigning a function to a global variable:

```lua
onStart = function(triggerId)
  local fullChat = getFullChat(triggerId)
  local lastChat = fullChat[#fullChat]

  if lastChat.role == 'user' and (utils.trim(lastChat.data) == '/config' or utils.trim(lastChat.data) == '/설정') then
    removeChat(triggerId, -1)
    addChat(triggerId, 'char', '<custom-config-panel />')
    stopChat(triggerId)
  end
end

-- To use Promise functions, wrap in async()
onOutput = async(function(triggerId)
  somePromiseFunction():await()
end)
```

- `onOutput(triggerId)`: Called after a chat response is received and appended.
- `onStart(triggerId)`: Called after the user sends a message and before the LLM request is made. Calling `stopChat()` here blocks the LLM request.

### listenEdit

Functions registered through `listenEdit(type, function(triggerId, data, meta))` run just before regexes of the same `type`. The `editRequest` type receives the entire prompt, unlike the other types.

```lua
listenEdit(
  'editDisplay',
  function(triggerId, data, meta)
    if meta and meta.index ~= nil then
      local position = meta.index - getChatLength(triggerId)
      if position < -5 then
        return data
      end
    end

    return data:gsub('abc', 'def')
  end
)

listenEdit(
  'editRequest',
  function(triggerId, data)
    for i = #data, 1, -1 do
      print(json.encode(data[i]))
    end
  end
)
```

### Button callbacks

Buttons are the only available UI interaction.

Use `risu-btn`, `risu-trigger`, and `onButtonClick`. Read `001-button-handlers.md` for details.

Use that resource only for custom handlers. Lightboard rerolls and interactions do not need custom button callbacks.
