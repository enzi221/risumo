# ♦️미니보드

(크롭 스크린샷...들? 편집해서 한장으로 만들듯)

게시판, 공지판, 일기장, 생각 훔쳐보기. 게시물과 댓글의 형태라면 뭐든 만들어 볼 수 있어요

(4색 테마 x 2색 밝기 스크린샷들)

## 권장 토글

모드

- 메인 (채팅 모델), 보조 (별도 설정 모델)

발동
누르면

- 매번 생성 시 질림

분량
4-7

사전설정
기본

- 기본 미니보드 스타일 (커뮤니티 말투 도가니탕)

주제

- 특정 주제의 게시판을 보고 싶을 때

느낌

- 특정 분위기나 말투 따위의 게시판을 만들고 싶을 때

사생활
강보호

- 주인공과 주변인의 성질/행적 등이 게시판에 얼마나 영향을 줄지, 강보호면 거의 주지 않음

주요인물
보존

다양성 강화

- 비슷한 상황에서 비슷한 응답만 보여서 질리면 체크

생각보조
적고 제거

- 사생활 보호가 중요하지 않고 프론티어 모델이면 "생각만" 설정으로 출력 절약 가능

컨텍
제거

- 게시판에 중요한 내용이 있거나 하면 포함으로 바꿔 진행한 후 제거로 변경 가능

## 토글 상세 설명

분량
게시글의 분량만 결정해요

사전설정
기본: 커뮤니티 말투 도가니탕, 느낌으로 세부 제어 가능
세계관정합: 커뮤니티 말투 지침 제외
생각: 대상의 머릿속 생각
감정: 대상의 감정들 의인화 (인사이드아웃 스타일)

주제
게시판 주제, 또는 대상이 누구인지

느낌
게시판 글 톤 앤 매너

사생활
이목집중: 모든 사람이 대상의 스토커임
자율: 지침 없음
약보호: 사생활 보호. 단, 사생활의 범위를 넘어나면 언급됨. 캐릭터들이 특징적인 일을 하거나 겪으면 그걸 다른 곳에서 자기가 똑같이 했다는 사람이 나오곤 함
강보호: 사생활 보호, 행동/사건 사칭 억제. 단, 사생활의 범위를 넘어나면 언급됨
언급금지: 무슨 일이 있어도 언급 금지

주요인물
보존: 캐릭터 목록이나 로어북, 작노 등에 명시한 캐릭터가 글/댓글을 쓸 경우 닉네임과 말투 특징 따위를 저장해놨다가 이후 계속 사용

미니콘 허용
끄면 미니콘 지침 제거

커스텀 렌더러 허용
끄면 항상 기본 미니보드 스킨 사용

다양성 강화
두 개의 응답을 생성하게 한 후 뒤의 것을 채택
